# Portfolio Website

Single-page portfolio built with React, Vite, and Tailwind CSS.

## What is included

- A mobile-first landing page with a strong hero section.
- A reusable portfolio card component.
- Four portfolio cards:
	- Personal information with prominent GitHub and LinkedIn links.
	- Bio summary.
	- Two project placeholders with structured content.
- Interactive card hover states with lift and shadow transitions.

## Development

Install dependencies and start the dev server:

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

## Notes

- Update the GitHub and LinkedIn URLs in the first card with your real profiles.
